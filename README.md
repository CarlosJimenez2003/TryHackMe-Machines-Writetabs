# 🛡️ TryHackMe Writeups

Repositorio personal con **writeups detallados de máquinas de TryHackMe**, documentando el proceso completo de explotación desde enumeración hasta acceso final.

---

## 📌 Objetivo

Este repositorio tiene como finalidad:

* 📖 Documentar mi aprendizaje en **ciberseguridad ofensiva**
* 🧠 Practicar metodologías reales de **pentesting**
* 🧪 Analizar vulnerabilidades y técnicas de explotación
* 🚀 Construir un portfolio técnico

---

## 🧠 Metodología

Cada máquina sigue una estructura similar:

1. 🔍 Enumeración (Nmap, Gobuster)
2. 🌐 Análisis web (Burp Suite)
3. 💉 Explotación (SQLi, RCE, etc.)
4. 🗄️ Post-explotación (credenciales, pivoting)
5. 🔐 Escalada de privilegios
6. 🏁 Obtención de flags
